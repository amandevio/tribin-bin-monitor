Flash the Tribin sensor

Put the sensor test code on your XIAO ESP32-C3 from this browser. No software to install.

1Wire the sensor (USB unplugged)

A02YYUW sensor wireXIAO pin
Red (power)3V3
Black (ground)GND
White (TX, data out)D7
Yellow (RX)Not connected

2Install the code

  1. Plug the XIAO into this computer with a data USB-C cable.
  2. Click Connect below, pick "USB JTAG/serial debug unit" from the list, and click Connect.
  3. Click Install Tribin Sensor Test, then Install. It takes about a minute.

This browser can't talk to USB devices. Open this page in Chrome or Edge on a computer.

This page needs a secure connection (https) to use USB.

If the XIAO doesn't appear in the list: unplug it, hold the B button, plug it back in, let go, and try again. After installing in this mode, press the R button once to start the code.

3See the readings

  1. Click Connect again and pick the XIAO.
  2. Choose Logs & Console.
  3. You should see lines like Distance: 42.3 cm Fill: 29% a few times a second. Move your hand toward the sensor and watch them change.

No readings? Check the wiring. If the colors on your cable are different, try the yellow wire in D7 instead of the white one. The sensor can't see anything closer than 3 cm.
